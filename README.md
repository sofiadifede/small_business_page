# Sally's Swimwear

A colorful landing page for a fake swimwear small business. It's built to practice HTML/CSS fundamentals and explore how AI tools can assist in front-end designing.

## What It Does

A website site featuring a header with navigation, a hero welcome section, a services showcase (custom design, alterations, repair), a call-to-action, and a footer with contact info.

## Technologies Used

- HTML
- style.CSS
- JavaScript

## How to Run

1. Clone or download this repository.
2. Make sure `index.html`, `style.css`, and `cc_7.js` are in the same folder.
3. Right click and open `index.html` in your browser.

## AI Assistance

I used AI to help style and polish this site. My starting CSS was a simple pink-and-yellow color scheme that was stagnent, so I asked AI to:

- Assist in making the design "more fun". It taught me how to add gradient animations, a moving header, and scaling hover effect on the service cards.
- Help me understand why my HTML had random syntax errors. They included unclosed quotes and parenthesis.

I reviewed every change, tested it in the browser, and adjusted colors/spacing to match my own taste rather than accepting suggestions blindly.

## What I Learned

- How small CSS techniques from AI combined to make a page feel more polished and interactive.
- The difference between centering an element's *contents* versus centering the *element itself* on the page.
- That AI tools are useful for helping design and understand syntax errors, but I still need to understand the overall CSS/HTML to review the issue in itself.
